# ChromaPress v1 Alpha 10

Part 2 Applications UX refinement.

- Application/Version/Description/State/Action columns are all user-resizable by dragging header separators.
- The Application column starts substantially wider.
- Application names are bold when expanded.
- Category, suite and subgroup rows have useful human descriptions instead of only "Expand".
- Home / Personal Quick view is deliberately narrower and split into Everyday essentials and Specialised / Advanced.
- Everyday Home groups cover internet/communication, writing/office, photos, video/music, books/podcasts, casual games and file handling when those programs are installed.
- Specialist Home groups separate torrent/file sharing, programming/web development, advanced audio/video editing (including Audacity when installed) and technical tools.
- Search remains global even when a Quick scenario is active.
- Every application row now has an icon. Linux theme icons are used when available; otherwise the bundled ChromaPress placeholder is used. Real ISO icon extraction remains a later lazy/cache enrichment and never blocks list display.
