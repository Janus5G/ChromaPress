# ChromaPress v1 Alpha 21

Part 2 safety/compliance correction.

- `School / Education` remains a first-class system-use profile.
- The bundled `ChromaLearn AI 0.3.0` recommendation is temporarily withdrawn.
- `bundled_apps/chromalearn_0.3.0_all.deb` is removed from the ChromaPress package.
- Global search no longer exposes ChromaLearn as a supported available/recommended application.
- Existing School / Education grouping and generic education-app discovery remain intact.
- Reintroduction requires a new reviewed package/version after child/privacy logging and data-retention compliance is complete.

This change does not affect the already approved Alpha 17 global search/profile marking, Alpha 19 profile switching, Alpha 20 auto-expanded recommendations, or other application profiles.
