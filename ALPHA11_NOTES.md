# ChromaPress v1 Alpha 11

Part 2 UX / review update.

- Home / Personal now keeps a visible `Internet, browser & email` everyday category, even if the current Quick catalogue has no matching launcher yet.
- Application rows use real action buttons: `Remove`, `Undo remove`, or disabled `Keep` when safe removal is not resolved.
- The right-side Changes panel can be collapsed/expanded with the thin arrow control at the far right. Its width can still be resized with the splitter when open.
- Changes includes a `Full overview` button leading to the live project plan.
- The Changes navigation page is now a real live `Current image plan` instead of a placeholder. It shows source, system scenario, detected application counts by category, staged additions, removals, and other changes.
- Build & Verify is now a real `Final build review` page. It provides the same consolidated plan and is intended to become the mandatory review immediately before generation. The generation button remains disabled until the real Build & Verify engine is connected.
- Application catalogue cache behavior from Alpha 9/10 remains unchanged and fast.
- Source ISO remains read-only; these changes are still declarative only.
